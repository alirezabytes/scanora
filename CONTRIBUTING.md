# Contributing to Scanora

Use [GitHub Issues](https://github.com/alirezabytes/scanora/issues) for bugs and improvement ideas. For a bug, include the operating system, Scanora revision, screen reader and version if used, steps to reproduce, what was announced or displayed, and what you expected. If a document or image is needed, use a synthetic or shareable sample. Keep credentials, private documents, and private diagnostic logs out of public issues.

Check [BUILDING.md](BUILDING.md) before opening a pull request. Include the behavior you changed and the checks you ran. For an accessibility change, describe how you reached and used the feature with a screen reader or the keyboard, and include the actual spoken text where practical.

Language contributions can cover interface strings, OCR samples, or speech testing. Include sample text you have permission to share and the expected reading order or pronunciation.
