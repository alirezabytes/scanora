# Scanora

Scanora is an accessibility app for blind and low-vision users on Android and Windows. It is in active development. Public installers are not available yet.

Scanora helps people read printed material and digital documents independently. Its offline tools are designed to keep working when internet access is unreliable. The project aims to serve users worldwide and expand language coverage for the interface, text recognition, and speech over time.

## Features in development

- Read text from photos, screenshots, and documents. Use the camera for live reading or scan a book with audio guidance and automatic page capture.
- Read documents aloud, create audiobooks, convert documents, and manage saved books and reading progress.
- Transcribe recordings, use spoken color announcements, and get image descriptions or ask questions about images with a configured online provider.
- Use Android TalkBack or a Windows screen reader to navigate. Handwriting recognition is experimental and varies with the input and available models.
